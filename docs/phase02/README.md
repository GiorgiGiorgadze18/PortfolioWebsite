# ფაზა 02 — პროექტები და დაკავშირება

ბრენჩი upgrade/phase01-identity, საწყისი ფაზა 01-ის კომიტი 6fdcf1c. ცვლილებები დრაფტ PR #24-ში გროვდება.

## პრობლემები და ცვლილებები

ადრე არქივის ბარათი პირდაპირ 3D არჩევას იწყებდა, ექვსი მიმართულებიდან კი მხოლოდ UI/UX და Graphics ფილტრები არსებობდა. ახლა Grid View მალავს 3D სექციას, ხოლო ?view=grid ვიზიტზე Three.js-ის ინიციალიზაცია იწყება 3D არჩევის შემდეგ. ბარათები დამოუკიდებელ დეტალების დიალოგს ხსნის. მისამართი #project/tsero და სხვა არსებული ID-ები პირდაპირ მუშაობს. ბრაუზერის უკან/წინ გადასვლა დიალოგის არჩევანსაც ასახავს.

MeeTab-სა და Tsero-ს დეტალებში Open in 3D Showroom ხსნის არსებულ სცენას და მის ფოკუსს. არქივში დაემატა ამ პორტფოლიოს რეალური სქრინი და აღწერა. შოურუმის მოწყობილობების რაოდენობა იგივეა. მონაცემები ერთი არსებული PROJECTS წყაროდან იკითხება, პორტფოლიოს ჩანაწერი მის არქივის კოლექციას ემატება. Home-ის შერჩეული ბარათების საერთო მონაცემებზე გადატანა არქიტექტურულ ფაზაში რჩება. კატეგორიებს მრავალჯერადი წევრობა აქვს, development ფილტრი ორ აპსა და პორტფოლიოს აჩვენებს. Neon Drift-ის დასამატებლად დადასტურებული მასალა კვლავ საჭიროა.

Contact-ში ფორმა თავიდანვე გამოსაყენებელია. ტერმინალის ტექსტი დეკორატიულია, დაშიფვრის მტკიცება ამოღებულია. ველები და გაგზავნა ჩვეულებრივადაა დასათაურებული, დამატებულია autocomplete, გაგზავნის, წარმატებისა და შეცდომის შეტყობინებები. გაგზავნისას ღილაკი იბლოკება, განმეორებით submit-ს ცალკე დამცავი state აქვს. შეცდომისას შეყვანილი ტექსტი რჩება. Formspree-ის იგივე action და სახელები ინარჩუნებს native POST-ს JavaScript-ის გარეშე. სპამის საწინააღმდეგო პროვაიდერის კონფიგურაცია ცალკე ანგარიშის მხარესაა შესამოწმებელი. რეალური შეტყობინებები არ გაგზავნილა.

გადაწყვეტილებები: 3D რჩება ჩვეულებრივი ვიზიტის საწყის ხედად, Grid-ს აქვს პირდაპირი URL. 3D ინტერაქტიული პრეზენტაციის შეცვლაზე ცალკე ნებართვის საჭიროება ამ მიდგომით მცირდება. ქარდების არჩევანი არქივში ჯერ ხელმისაწვდომ დეტალებს ხსნის და აპის მომხმარებელს სცენაში გადასვლას სთავაზობს.
