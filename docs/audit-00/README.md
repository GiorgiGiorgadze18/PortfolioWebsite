## შემდგომი ფაზების მიღების კრიტერიუმები

1. **იდენტობა და კონტენტი.** ოთხივე გვერდზე ერთიანი პროფესიული პოზიციონირება, CV-ზე ფაქტობრივი შემოწმება, GitHub-ის სწორი პროფილი, სამუშაოების ხილვადობა გამოცდილებამდე. ოთხ მიმართულებად დაჯგუფებისას შენარჩუნდეს მოწონებული ჰოლოგრაფიული ინტერაქცია. არსებითი ვიზუალური ცვლილებისთვის ცალკე მაკეტი და თანხმობა.
2. **პროექტები და UX.** ხუთი არსებული პროექტი და პორტფოლიო პირდაპირი მისამართებით, დამოუკიდებლად ხელმისაწვდომი Grid, კლავიატურით ფილტრები, მოქნილი კატეგორიები. ფორმა დაუყოვნებლივ აქტიურია. Formspree-ის წარმატება, შეცდომა და განმეორებითი გაგზავნა მოწმდება ლოკალური იმიტაციით.
3. **მოძრაობა.** თითოეული მოდულისთვის ჩვეულებრივი, reduced, touch, offscreen და hidden მდგომარეობის შემოწმება. გამეორებითი შესვლა/გამოსვლა, უკუსქროლი და ფოკუსის დაბრუნება ვიზუალური ნახტომის გარეშე.
4. **არქიტექტურა და აქტივები.** გაზომილი დუბლირების შემცირება მცირე ნაბიჯებით. ცენტრალიზებული პროექტის მონაცემები, ორიგინალი ნამუშევრებისა და ორივე დემოს საზღვრების შემოწმება.
5. **სისწრაფე, ხელმისაწვდომობა და უსაფრთხოება.** შედარებადი განმეორებითი ლაბორატორიული გაზომვები, axe მიგნებების ხელით შემოწმება, 320px/200% reflow, კლავიატურით კრიტიკული გზები. დადასტურებული მძიმე პრობლემები გამოსწორდეს. WCAG ან საველე Core Web Vitals დასკვნას ცალკე მტკიცებულება სჭირდება.
6. **SEO.** ოთხივე გვერდზე უნიკალური metadata, canonical, გაზიარების სურათი, სტრუქტურირებული მონაცემების ვალიდაცია, sitemap და 404 შემოწმებული /PortfolioWebsite/ პრეფიქსით.
7. **Lab და დამატებითი ფუნქციები.** მხოლოდ დადასტურებული ექსპერიმენტი და გაზომვადი სარგებელი. ცარიელი დანიშნულებების რაოდენობა ნული. სამომავლო Case Study-ისთვის მონაცემთა და ბმულის ინტეგრაციის წერტილი.
8. **საბოლოო QA.** სიგანეები 320–2560px, tablet/landscape, zoom, reduced motion, WebGL fallback, ორივე დემო და touch პოლიტიკა. საწყისთან ვიზუალური და გაზომვადი შედარება, rollback-ის რეპეტიცია და გამოქვეყნების ცალკე ნებართვა.
