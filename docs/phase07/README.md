# ფაზა 07 — Creative Lab და ინტერაქტიული მაგალითი

2026-11-26. ბრენჩი upgrade/phase01-identity. საწყისი SHA 2832b35. სტატუსი დასრულებულია შერჩეულ ექსპერიმენტსა და დამატებითი ფუნქციების შეფასებაში. საერთო რელიზის ღია პუნქტები docs/OPEN_VERIFICATION.md-ში რჩება.

## აღმოჩენილი საჭიროება და არჩეული მოცულობა

პორტფოლიოს დისციპლინების ქარდებს უკვე ჰქონდა რეალური CSS 3D depth, pointer/touch tilt და დამპინგი, მაგრამ სტუმარი მის პარამეტრებს ვერ ცდიდა. ეს არსებული კომპონენტი შეირჩა Lab-ის პირველ ნამუშევრად. ახალი გვერდი lab.html აჩვენებს იმავე ძრავას რეალური კონტროლებით. ნავიგაციაში Lab დაემატა მას შემდეგ, რაც მოქმედი ექსპერიმენტი შეიქმნა.

Neon Drift-ის მასალა ამ ეტაპზე ხელმისაწვდომ წყაროებში ვერ დადასტურდა. დაკავშირებულ GitHub repository search-ში Neon მოთხოვნამ ცარიელი სია დააბრუნა. ეს პროექტის არარსებობას არ ადასტურებს. მისი გამოქვეყნებისთვის საჭიროა გადამოწმებადი რეპოზიტორია, ავტორობა, აქტივები და აღწერა.

Command palette შეფასდა და გადაიდო: ახლა ხუთი ძირითადი გვერდი, პირდაპირი პროექტის ბმულები და native keyboard კონტროლები არსებობს. ამ ზომის ნავიგაციაზე მეორე command მენიუს დამატებითი სარგებელი ჯერ არ გამოკვეთილა. გადაწყვეტილება შეიძლება შეიცვალოს ექსპერიმენტების/გვერდების ზრდის ან გამოყენების დაკვირვების შემდეგ.

## შესრულებული ცვლილებები

Lab-ში ერთი ჰოლოგრაფიული ქარდია, ორი პარამეტრით: Tilt strength და Reflection. Pause/Resume აჩერებს ქარდის pointer/idle მოძრაობას, Reset აბრუნებს საწყის პარამეტრებს. სლაიდერები native range ელემენტებია და კლავიატურის ისრებითაც მუშაობს. დათვლები მართვის ფაქტობრივ მნიშვნელობას ასახავს.

shared hologram.js ახლა data-hologram კონტეინერის ქარდებსაც პოულობს. არჩევითი strength მონაცემი მხოლოდ Lab-ში ივსება, Home-ის ოთხი ქარდის ნაგულისხმევი კოეფიციენტი იგივეა. Lab-ის UI ლოგიკას საკუთარი requestAnimationFrame მარყუჟი არ აქვს; იყენებს არსებულ მოძრავი ქარდების ერთ scheduler-ს და CSS float-ს.

Pause ინახება გვერდის მიმდინარე სესიაში, visibility-ის ცვლილების შემდეგაც. reduced-motion რეჟიმში tilt და pause კონტროლები გამორთულია, reflection კი გამოსაყენებელია. JavaScript-ის გარეშე ჩანს სტატიკური ქარდი და მოკლე განმარტება. საჭირო შესაძლებლობის არქონისას controls დამალულია და static preview მესიჯი ჩანს.

Reset-ის პირველი ტესტი ვერ გავიდა: native form reset-ისა და queued განახლების რიგითობამ output ტექსტის დაბრუნება შეუშალა. handler ახლა default reset-ს აჩერებს და ორ input-ს, output-სა და pause მდგომარეობას ერთად აღადგენს. გამეორებულმა ტესტმა ორივე ბრაუზერში გაიარა. Reflection-ის ადგილობრივი წესი დაკონკრეტდა, რათა pointer hover-ისასაც სლაიდერის არჩეული გამჭვირვალობა დარჩეს. მისი ტესტი ელოდება რეალური transition-ის დასრულებას.

ხუთივე გვერდზე მთავარი/მობილური/ქვედა ნავიგაციის რიგი ერთიანია: Home, Projects, Lab, About, Contact. აქტიურ გვერდს aria-current მიენიჭა. მთავარ shell-ში არსებული Connect CTA მობილური სიის ბოლოსაა. Footer-ის საკუთარ სტილებს primary nav-ის კლასები არ მიენიჭა.

Lab-ს აქვს canonical, social metadata და WebPage/CreativeWork JSON-LD. sitemap-ში მეხუთე canonical დაემატა. არსებული SEO ტესტი განახლდა ხუთი გვერდისთვის.

## ვიზუალური გადაწყვეტილებები

გამოყენებულია არსებული მუქი ფონი, ცისფერი აქცენტი, Inter/Space Grotesk და ჰოლოგრაფიული ზედაპირი. დესკტოპზე განმარტება და ქარდი გვერდიგვერდაა, მობილურზე ვერტიკალურად ლაგდება. კონტროლები ვიზუალურ პარამეტრებს მხოლოდ ამ ექსპერიმენტში ცვლის. Home-ის ხელახალ დიზაინზე გადაწყვეტილება არ მიღებულა.

ჩემი არჩეული დეტალებია ერთი კომპონენტით Lab-ის დაწყება, სწორედ tilt/reflection პარამეტრების გამოტანა და ნავიგაციის ერთიანი რიგი. ექსპერიმენტი ბრაუზერში მეხსიერებით იმართება, პარამეტრები ანგარიშზე ან სერვერზე არ ინახება.
