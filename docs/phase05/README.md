## მიგნებები და ცვლილებები

Home-ისა და Grid არქივის საწყისი ვიზიტები ითხოვდა დიდ ორიგინალებს preview-სთვის. შეიქმნა ოთხი WebP წინასწარი გამოსახულება 90 quality-ით, 1280×1600 ჩარჩოში ჩატევით. სცენის მაღალი ხარისხის ეკრანები და ორიგინალ artwork-ზე პირდაპირი წვდომა შენარჩუნებულია. ვიზუალური გვერდიგვერდ მიმოხილვა შესრულდა. assets.json აღწერს თითო წყაროს, ზომებს და შექმნილ ფაილს. საერთო მონაცემებს thumbnail ველი დაემატა; Home-ის გენერატორი და არქივი მას იყენებს, ხოლო დეტალების სრული სურათი კვლავ ორიგინალია.

დესკტოპზე სცენა MeeTab-ის 4.9MB დოკუმენტს წინასწარ ითხოვდა. ინიციალიზაციის ეს მოთხოვნა მოიხსნა. პროექტის არჩევისას არსებული readiness/bridge მექანიზმი იტვირთება, Try Now-ის ქცევა კი კვლავ რეალური readiness-ის საფუძველზეა.

საწყის axe სკანში Home და Contact-ის mobile-menu იღებდა aria-hidden-focus-ს, ხოლო Projects-ის All ფილტრის რაოდენობას ფერის კონტრასტის მიგნება ჰქონდა. დახურული მენიუ inert გახდა, გახსნისას ფოკუსი პირველ ბმულზე გადადის, Escape აბრუნებს ღილაკზე. დესკტოპზე დაბრუნებისას მენიუ იკეტება. ძირითადი shell-ის გახსნილ მენიუში Tab-ის ციკლი შეესაბამება მის overlay ქცევას. Projects-ის ცალკე მენიუსაც დაემატა გახსნის ფოკუსი და Escape/resize. ფილტრის რაოდენობის ტექსტს სრული opacity აქვს. დიალოგის დახურვის კონტროლს მინიმუმ 44px ზომა დაემატა.

## უსაფრთხოების მიმოხილვა

MeeTab-ის iframe ინარჩუნებს sandbox allow-scripts-ს, opaque origin-სა და შეზღუდულ CSP-ს. parent ამოწმებს შეტყობინების source-ს ცნობილი iframe-ის contentWindow-სთან. wheel ხიდს დაემატა delta-ს საბოლოო რიცხვისა და mode-ის 0/1/2 მნიშვნელობის შემოწმება, რომ არასწორმა მონაცემმა სცენის მასშტაბი NaN-ად არ აქციოს. opaque iframe-ისთვის targetOrigin '*' საჭირო რჩება; შეტყობინება მიემართება მხოლოდ მის ცნობილ contentWindow-ს.

Tsero-ს არსებული ექსპორტი same-origin მოდულებსა და საკუთარ CSP-ს იყენებს, form-action none, base-uri none და object-src none შეზღუდვებით. CSP-ის გაძლიერება ბრმად არ განხორციელებულა. ორიგინალი აპების ბიზნესლოგიკის ფაილები byte comparison-ით შედარდა საწყის კომიტს და დაემთხვა. ამ ფაზაში backend/auth/database დამატებული არ არის.

plaintext წყაროებში ტიპური AWS access key, GitHub token და private-key სათაურების ძიებამ დამთხვევა არ დააბრუნა. ეს შეზღუდული ძიებაა, არქივებისა და Git ისტორიის სრულ secret scan-ს არ წარმოადგენს. ფორმის მონაცემები Formspree-ს გადაეცემა HTTPS მისამართზე. მისი ანგარიშის spam/rate-limit პარამეტრები ამ გარემოდან არ შემოწმებულა. GitHub Pages-ის ჩვეულებრივი branch hosting თვითნებურ HTTP security response headers-ს არ გვაძლევს; ასეთი კონფიგურაცია არ გამოცხადებულა შესრულებულად. არსებული CSP შეზღუდვები აღწერილია დემოების დოკუმენტებში. მესამე მხარის JS dependency ვალიდაცია ცალკე backlog-შია.
